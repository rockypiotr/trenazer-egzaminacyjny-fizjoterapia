# Trenażer egzaminacyjny z fizjoterapii

[Otwórz trenażer](https://rockypiotr.github.io/trenazer-egzaminacyjny-fizjoterapia/)

Fiszki, quizy, pytania otwarte, przypadki praktyczne i próbny egzamin z wad postawy oraz rehabilitacji pulmonologicznej. Trenażer działa w przeglądarce bez instalacji i logowania. Postępy zapisują się w przeglądarce. Można je przenieść z lokalnego pliku HTML lub na inne urządzenie przez eksport i import JSON w zakładce „Postępy i ustawienia”.

## Publikacja w GitHub Pages

1. Umieść `index.html` w katalogu głównym gałęzi `main` publicznego repozytorium.
2. W repozytorium otwórz **Settings → Pages**. Wybierz **Deploy from a branch**, gałąź **main** i katalog **/ (root)**. Kliknij **Save**.
3. Po zakończeniu wdrożenia otwórz adres podany w **Settings → Pages**. Dla repozytorium projektu ma on postać `https://<użytkownik>.github.io/<repozytorium>/`.

Cała aplikacja, pytania i ilustracje są osadzone w `index.html`. Aktualizację publikujesz, wypychając zmieniony plik na `main`.
